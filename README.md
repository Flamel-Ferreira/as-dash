# as-dash

## O que é esse projeto?
As-Dash é um projeto de uma dashboarde de gerenciamento de conflitos para o sistema de RPG de mesa Assimilação criado por Rafael "Rakin" Knittel.

## Porque usar?
O sistema de assimilação requer do Assimilador (Mestre do RPG) o gerenciamento de custo e alocação de recursos adquiridos através da rolagem de dados, isso pode se tornar um pouco demais considerando que os conflitos podem ter diversos objetivos principais e secundários, ameaças condicionantes e ativações.

Essa dashboard tem a intensão de uma ferramenta para facilitar a alocação desses recursos para que o Assimilador possa se concentrar na narração no momento do conflito.

## Como funciona?
Inicialmente a dashboard tem como objetivo apresentar ferramentas para **cadastro e gerenciamento de conflitos**. E posteriormente para **rolagens de assimilação** e de ferramentas referente a **geração de aventuras**. 

### • Funcionalidades: 
- Criação de conflito por meio de formulário;
- Seleção de conflitos criados;
- Gerenciamento de conflitos:
  - Rolagem de dados;
  - Alocação manual recursos (`sucesso`, `adaptação` e `pressão`) em ativações, objetivos;
  - Alocação aleatória automática de recursos;
- Exportação e Importação de conflitos criados na dashboard;
